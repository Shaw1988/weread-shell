# weread-shell

微信读书网页版的桌面外壳（**非官方**）。用 Electron 打开完整网页版，去掉主页推荐流，补上几个网页版没有的小功能。

## 为什么做这个

微信读书有官方桌面端，但它本质是网页版套壳，功能比网页版还少。这个项目反过来：直接加载完整网页版，把网页版的全部功能保留下来，只在外层加东西。

## 功能

- **独立窗口**：有自己的任务栏图标和窗口，不再是浏览器里的一个标签页
- **护眼配色**：日间模式把正文背景改成淡绿 `#CCE8CF`、页面底色改成淡青 `#C0D3D7`，夜间模式保持官方原色
- **阅读计时挂件**：右下角半透明电子表，单击在两种内容间切换
  - `今天已阅读 12分钟`：只统计真正在读的时间，跨天自动归零
  - `预计 18分钟 读完本章`：按本章剩余字数和 400 字/分钟估算
- **启动直达**：打开就是上次读到的位置；未登录时自动弹出扫码框
- **主页净化**：隐藏推荐、榜单、分类卡片
- **快捷键**：`Ctrl+Shift+H` 沉浸全屏、`Ctrl+Shift+T` 隐藏挂件、`F12` 开发者工具

## 下载使用

到 [Releases](../../releases) 下载 `WereadDesktop-x.x.x.exe`，双击即可。

- 单文件绿色版，不需要安装
- 首次运行会在 exe 同目录生成 `data` 文件夹，登录态和缓存都放在里面
- 如果放在没有写入权限的目录，会自动改用系统用户目录
- 未签名，Windows 可能提示"未知发布者"，点"更多信息 → 仍要运行"

## 从源码运行

```bash
npm install
npm start
```

打包成单文件 exe：

```bash
npm run dist
```

产物在 `release/` 下。

## 已知限制

- 只支持 Windows 10/11 x64
- 默认关闭硬件加速：部分显卡驱动下 Chromium 会崩溃，阅读场景用软件渲染反而更稳。想开启可在 `src/main.js` 去掉 `app.disableHardwareAcceleration()`
- 注入的样式依赖微信读书的页面结构，官方改版后可能需要调整选择器
